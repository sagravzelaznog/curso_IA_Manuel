Contenido

Listas

Las listas son colecciones ordenadas y mutables de elementos. Pueden contener diferentes tipos de datos.

Creación de listas:

# Lista vacía
mi_lista = []

# Lista con elementos
numeros = [1, 2, 3, 4, 5]
mezcla = [1, "hola", 3.14, True]

# Usando el constructor list()
otra_lista = list((1, 2, 3))

Operaciones comunes:

# Acceso a elementos
primer_elemento = numeros[0]  # 1
ultimo_elemento = numeros[-1]  # 5

# Modificar elementos
numeros[0] = 10

# Añadir elementos
numeros.append(6)         # Añade al final
numeros.insert(1, 1.5)    # Inserta en posición específica

# Eliminar elementos
del numeros[0]           # Elimina por índice
numeros.remove(3)         # Elimina la primera ocurrencia del valor
valor_eliminado = numeros.pop()  # Elimina y devuelve el último elemento

# Longitud de la lista
tamano = len(numeros)     # Devuelve 5

Tuplas

Las tuplas son similares a las listas pero son inmutables (no se pueden modificar después de crearse).

Creación de tuplas:

# Tupla vacía
mi_tupla = ()

# Tupla con un elemento (¡cuidado con la coma!)
una_tupla = (1,)  # Correcto
no_es_tupla = (1)  # Incorrecto, es un entero

# Tupla con múltiples elementos
colores = ('rojo', 'verde', 'azul')

# Usando el constructor tuple()
otra_tupla = tuple([1, 2, 3])

Operaciones comunes:

# Acceso a elementos
primer_color = colores[0]  # 'rojo'

# Desempaquetado
a, b, c = colores  # a='rojo', b='verde', c='azul'

# Longitud
tamano = len(colores)  # 3

# Las tuplas no pueden modificarse después de crearse
# Esto dará error:
# colores[0] = 'amarillo'  # TypeError

Conjuntos

Los conjuntos son colecciones no ordenadas de elementos únicos.

Creación de conjuntos:

# Conjunto vacío
mi_conjunto = set()  # ¡No usar {} que crea un diccionario!

# Conjunto con elementos
frutas = {'manzana', 'banana', 'cereza'}

# Usando el constructor set()
otro_conjunto = set([1, 2, 2, 3, 4])  # {1, 2, 3, 4}

Operaciones comunes:

# Añadir elementos
frutas.add('naranja')

# Eliminar elementos
frutas.remove('banana')  # Lanza error si no existe
frutas.discard('banana')  # No lanza error

# Operaciones de conjuntos
A = {1, 2, 3}
B = {3, 4, 5}

union = A | B          # {1, 2, 3, 4, 5}
interseccion = A & B   # {3}
diferencia = A - B     # {1, 2}
diferencia_simetrica = A ^ B  # {1, 2, 4, 5}

Diccionarios

Los diccionarios almacenan pares clave-valor y son muy útiles para representar datos estructurados.

Creación de diccionarios:

# Diccionario vacío
mi_diccionario = {}
otro_diccionario = dict()

# Diccionario con elementos
estudiante = {
    'nombre': 'Juan',
    'edad': 20,
    'cursos': ['Matemáticas', 'Programación'],
    'activo': True
}

Operaciones comunes:

# Acceso a valores
nombre = estudiante['nombre']  # 'Juan'
edad = estudiante.get('edad')  # 20

# Añadir o modificar valores
estudiante['edad'] = 21
estudiante['email'] = 'juan@ejemplo.com'

# Eliminar elementos
del estudiante['activo']
email = estudiante.pop('email', None)  # Elimina y devuelve el valor

# Obtener claves, valores y pares
claves = estudiante.keys()     # dict_keys(['nombre', 'edad', 'cursos'])
valores = estudiante.values()  # dict_values(['Juan', 21, ['Matemáticas', 'Programación']])
pares = estudiante.items()     # dict_items([('nombre', 'Juan'), ...])

# Verificar existencia de clave
if 'nombre' in estudiante:
    print('El estudiante tiene nombre')

Ejercicios Prácticos

Ejercicio 1: Lista de Compras

Crea un programa que permita al usuario gestionar una lista de compras. Debe permitir:

  1. Agregar elementos a la lista
  2. Eliminar elementos de la lista
  3. Mostrar todos los elementos de la lista
  4. Verificar si un elemento está en la lista
  5. Salir del programa
def lista_compras():
    compras = []
    
    while True:
        print("\n--- Lista de Compras ---")
        print("1. Agregar artículo")
        print("2. Eliminar artículo")
        print("3. Ver lista")
        print("4. Buscar artículo")
        print("5. Salir")
        
        opcion = input("Selecciona una opción: ")
        
        if opcion == '1':
            articulo = input("Ingresa el artículo a agregar: ")
            compras.append(articulo)
            print(f"'{articulo}' ha sido agregado a la lista.")
            
        elif opcion == '2':
            if not compras:
                print("La lista está vacía.")
                continue
                
            print("\nLista actual:")
            for i, articulo in enumerate(compras, 1):
                print(f"{i}. {articulo}")
                
            try:
                num = int(input("Número del artículo a eliminar: "))
                if 1 <= num <= len(compras):
                    eliminado = compras.pop(num - 1)
                    print(f"'{eliminado}' ha sido eliminado de la lista.")
                else:
                    print("Número inválido.")
            except ValueError:
                print("Por favor ingresa un número válido.")
                
        elif opcion == '3':
            if not compras:
                print("La lista está vacía.")
            else:
                print("\n--- Tu lista de compras ---")
                for i, articulo in enumerate(compras, 1):
                    print(f"{i}. {articulo}")
                    
        elif opcion == '4':
            busqueda = input("Ingresa el artículo a buscar: ")
            if busqueda in compras:
                print(f"'{busqueda}' está en la lista.")
            else:
                print(f"'{busqueda}' no está en la lista.")
                
        elif opcion == '5':
            print("¡Hasta luego!")
            break
            
        else:
            print("Opción no válida. Por favor intenta de nuevo.")

# Para ejecutar el programa:
# lista_compras()

Ejercicio 2: Agenda de Contactos

Crea un programa que funcione como una agenda de contactos. Debe permitir:

  1. Agregar un nuevo contacto (nombre y teléfono)
  2. Buscar un contacto por nombre
  3. Eliminar un contacto
  4. Mostrar todos los contactos
  5. Salir del programa
def agenda_contactos():
    contactos = {}
    
    while True:
        print("\n--- Agenda de Contactos ---")
        print("1. Agregar contacto")
        print("2. Buscar contacto")
        print("3. Eliminar contacto")
        print("4. Mostrar todos los contactos")
        print("5. Salir")
        
        opcion = input("Selecciona una opción: ")
        
        if opcion == '1':
            nombre = input("Nombre del contacto: ")
            if nombre in contactos:
                print("¡Este contacto ya existe!")
                continue
                
            telefono = input("Número de teléfono: ")
            contactos[nombre] = telefono
            print(f"Contacto '{nombre}' agregado correctamente.")
            
        elif opcion == '2':
            nombre = input("Nombre a buscar: ")
            if nombre in contactos:
                print(f"{nombre}: {contactos[nombre]}")
            else:
                print("Contacto no encontrado.")
                
        elif opcion == '3':
            nombre = input("Nombre del contacto a eliminar: ")
            if nombre in contactos:
                del contactos[nombre]
                print(f"Contacto '{nombre}' eliminado.")
            else:
                print("Contacto no encontrado.")
                
        elif opcion == '4':
            if not contactos:
                print("No hay contactos en la agenda.")
            else:
                print("\n--- Tus contactos ---")
                for nombre, telefono in contactos.items():
                    print(f"{nombre}: {telefono}")
                    
        elif opcion == '5':
            print("¡Hasta luego!")
            break
            
        else:
            print("Opción no válida. Por favor intenta de nuevo.")

# Para ejecutar el programa:
# agenda_contactos()

Resumen

Listas

  • Ordenadas y mutables
  • Sintaxis: [1, 2, 3]
  • Métodos útiles: append(), remove(), pop()

Tuplas

  • Ordenadas e inmutables
  • Sintaxis: (1, 2, 3)
  • Útiles para datos que no cambian

Conjuntos

  • No ordenados y sin duplicados
  • Sintaxis: {1, 2, 3}
  • Operaciones de conjuntos: unión, intersección, etc.

Diccionarios

  • Pares clave-valor
  • Sintaxis: {"clave": "valor"}
  • Acceso rápido por clave
