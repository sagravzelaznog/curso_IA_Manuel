Sesión 1.10: Estructuras de Control en Python

Duración: 60 minutos

Objetivos de Aprendizaje

  • Comprender el uso de estructuras condicionales (if, elif, else)
  • Dominar los diferentes tipos de bucles (for, while)
  • Aplicar estructuras de control anidadas
  • Utilizar break, continue y pass en bucles
  • Resolver problemas prácticos con estructuras de control

1. Estructuras Condicionales

Condicional if

# Estructura básica de if
edad = 18
if edad >= 18:
    print("Eres mayor de edad")

Condicional if-else

# Estructura if-else
nota = 7
if nota >= 6:
    print("¡Aprobado!")
else:
    print("Reprobado")

Condicional if-elif-else

# Estructura if-elif-else
puntaje = 85

if puntaje >= 90:
    print("Excelente (A)")
elif puntaje >= 80:
    print("Muy bien (B)")
elif puntaje >= 70:
    print("Bien (C)")
else:
    print("Necesitas mejorar")

2. Bucles en Python

Bucle for

# Recorrer una lista
frutas = ["manzana", "banana", "cereza"]
for fruta in frutas:
    print(f"Me gusta la {fruta}")

# Usando range()
for i in range(5):  # 0, 1, 2, 3, 4
    print(f"Número: {i}")

# Con inicio y fin
for i in range(2, 6):  # 2, 3, 4, 5
    print(i)

# Con paso
for i in range(0, 10, 2):  # 0, 2, 4, 6, 8
    print(i)

Bucle while

# Contador con while
contador = 0
while contador < 5:
    print(f"Contador: {contador}")
    contador += 1

# Bucle con condición de salida
respuesta = ""
while respuesta.lower() != "salir":
    respuesta = input("Escribe 'salir' para terminar: ")
    print(f"Escribiste: {respuesta}")

3. Estructuras de Control Anidadas

# Ejemplo de estructuras anidadas
for i in range(1, 6):
    print(f"\nTabla del {i}:")
    print("-" * 12)
    
    j = 1
    while j <= 10:
        if i % 2 == 0:  # Si es par
            print(f"{i} x {j:2} = {i*j:2}  (par)")
        else:
            print(f"{i} x {j:2} = {i*j:2}  (impar)")
        j += 1

4. Control de Flujo en Bucles

break, continue y pass

# Uso de break
print("Ejemplo de break:")
for i in range(10):
    if i == 5:
        break  # Sale del bucle cuando i es 5
    print(i)

# Uso de continue
print("\nEjemplo de continue:")
for i in range(5):
    if i == 2:
        continue  # Salta a la siguiente iteración cuando i es 2
    print(i)

# Uso de pass
print("\nEjemplo de pass:")
for i in range(3):
    pass  # No hace nada, se usa como marcador de posición
    print("Después de pass")

Ejercicio Práctico

Crea un programa que simule un cajero automático con las siguientes características:

  1. El saldo inicial es de $10,000
  2. Muestra un menú con opciones: Consultar saldo, Retirar, Depositar, Salir
  3. Usa estructuras de control para manejar las diferentes opciones
  4. Valida que no se pueda retirar más dinero del disponible
  5. El programa debe continuar ejecutándose hasta que el usuario elija Salir
# Solución del cajero automático
saldo = 10000

while True:
    print("\n=== CAJERO AUTOMÁTICO ===")
    print("1. Consultar saldo")
    print("2. Retirar efectivo")
    print("3. Depositar efectivo")
    print("4. Salir")
    
    opcion = input("\nSeleccione una opción (1-4): ")
    
    if opcion == "1":
        print(f"\nSu saldo actual es: ${saldo:,.2f}")
        
    elif opcion == "2":
        try:
            monto = float(input("\nIngrese el monto a retirar: "))
            if monto <= 0:
                print("El monto debe ser mayor a cero.")
            elif monto > saldo:
                print("Fondos insuficientes.")
            else:
                saldo -= monto
                print(f"Retiro exitoso. Su nuevo saldo es: ${saldo:,.2f}")
        except ValueError:
            print("Por favor ingrese un monto válido.")
            
    elif opcion == "3":
        try:
            monto = float(input("\nIngrese el monto a depositar: "))
            if monto <= 0:
                print("El monto debe ser mayor a cero.")
            else:
                saldo += monto
                print(f"Depósito exitoso. Su nuevo saldo es: ${saldo:,.2f}")
        except ValueError:
            print("Por favor ingrese un monto válido.")
            
    elif opcion == "4":
        print("\n¡Gracias por usar nuestro cajero automático!")
        break
        
    else:
        print("\nOpción no válida. Por favor seleccione una opción del 1 al 4.")

Resumen de la Sesión

  • Las estructuras condicionales (if, elif, else) permiten ejecutar código basado en condiciones.
  • Los bucles (for, while) permiten repetir bloques de código.
  • Las estructuras de control pueden anidarse para crear lógicas más complejas.
  • Las palabras clave break, continue y pass ofrecen mayor control sobre el flujo de los bucles.
  • Las estructuras de control son fundamentales para crear programas interactivos y dinámicos.
