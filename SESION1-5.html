Introducción a las Funciones

Las funciones son bloques de código reutilizables que realizan una tarea específica. Nos permiten organizar el código en partes más pequeñas y manejables, evitando la repetición y facilitando el mantenimiento.

Dato curioso: En programación, el principio DRY (Don't Repeat Yourself) nos anima a no repetir código. Las funciones son una de las mejores maneras de seguir este principio.

1. Definición y Llamada de Funciones

1.1 Sintaxis Básica

Para definir una función en Python, usamos la palabra clave def seguida del nombre de la función y paréntesis ().

# Definición de una función simple
def saludar():
    print("¡Hola, bienvenido al curso de IA!")

# Llamada a la función
saludar()  # Imprime: ¡Hola, bienvenido al curso de IA!

1.2 Funciones con Parámetros

Las funciones pueden recibir parámetros para procesar datos específicos.

def saludar_personalizado(nombre):
    print(f"¡Hola {nombre}, bienvenido al curso de IA!")

saludar_personalizado("Ana")  # ¡Hola Ana, bienvenido al curso de IA!
saludar_personalizado("Carlos")  # ¡Hola Carlos, bienvenido al curso de IA!

1.3 Parámetros por Defecto

Podemos asignar valores por defecto a los parámetros.

def saludar_completo(nombre, mensaje="Bienvenido"):
    print(f"{mensaje}, {nombre}.")

saludar_completo("Ana")  # Bienvenido, Ana.
saludar_completo("Carlos", "Hola de nuevo")  # Hola de nuevo, Carlos.

Ejercicio Práctico 1

Crea una función llamada calcular_edad que reciba el año de nacimiento y devuelva la edad actual. Luego, pide al usuario su año de nacimiento y muestra su edad.

from datetime import datetime

def calcular_edad(anio_nacimiento):
    anio_actual = datetime.now().year
    return anio_actual - anio_nacimiento

# Solicitar año de nacimiento al usuario
anio = int(input("Ingresa tu año de nacimiento: "))
edad = calcular_edad(anio)
print(f"Tienes {edad} años.")

2. Valores de Retorno

Las funciones pueden devolver valores usando la palabra clave return.

2.1 Retorno de un solo valor

def sumar(a, b):
    return a + b

resultado = sumar(5, 3)  # resultado = 8

2.2 Retorno de múltiples valores

En Python, podemos devolver múltiples valores separados por comas.

def operaciones(a, b):
    suma = a + b
    resta = a - b
    multiplicacion = a * b
    division = a / b if b != 0 else "Error: División por cero"
    return suma, resta, multiplicacion, division

# Desempaquetado de la tupla retornada
s, r, m, d = operaciones(10, 2)
print(f"Suma: {s}, Resta: {r}, Multiplicación: {m}, División: {d}")

Ejercicio Práctico 2

Crea una función llamada es_primo que reciba un número y devuelva True si es primo y False en caso contrario. Luego, pide al usuario un número y muestra si es primo o no.

def es_primo(numero):
    if numero <= 1:
        return False
    for i in range(2, int(numero ** 0.5) + 1):
        if numero % i == 0:
            return False
    return True

# Solicitar número al usuario
num = int(input("Ingresa un número mayor que 1: "))
if es_primo(num):
    print(f"{num} es un número primo.")
else:
    print(f"{num} no es un número primo.")

3. Alcance de Variables (Scope)

El alcance de una variable determina dónde puede ser accedida dentro del código.

3.1 Variables Locales

Solo existen dentro de la función donde fueron definidas.

def funcion_ejemplo():
    variable_local = "Solo visible dentro de la función"
    print(variable_local)

funcion_ejemplo()  # Imprime el valor
# print(variable_local)  # Error: NameError: name 'variable_local' is not defined

3.2 Variables Globales

Pueden ser accedidas en cualquier parte del código.

variable_global = "Puedo ser accedida en cualquier lugar"

def mostrar_global():
    print(variable_global)  # Acceso a variable global

mostrar_global()  # Imprime la variable global

3.3 La palabra clave global

Permite modificar una variable global desde dentro de una función.

contador = 0

def incrementar_contador():
    global contador
    contador += 1
    return contador

print(incrementar_contador())  # 1
print(incrementar_contador())  # 2

Precaución: El uso excesivo de variables globales puede hacer que el código sea difícil de mantener y depurar. Es preferible pasar los valores como parámetros y devolver resultados.

4. Argumentos Flexibles

4.1 Argumentos arbitrarios (*args)

Permite pasar un número variable de argumentos a una función.

def sumar_numeros(*args):
    return sum(args)

print(sumar_numeros(1, 2, 3))  # 6
print(sumar_numeros(5, 10, 15, 20))  # 50

4.2 Argumentos de palabras clave arbitrarias (**kwargs)

Permite pasar un número variable de argumentos de palabras clave.

def mostrar_info(**kwargs):
    for clave, valor in kwargs.items():
        print(f"{clave}: {valor}")

mostrar_info(nombre="Ana", edad=25, ciudad="Madrid")
# nombre: Ana
# edad: 25
# ciudad: Madrid

Ejercicio Práctico 3

Crea una función llamada promedio que acepte un número variable de argumentos numéricos y devuelva su promedio. La función también debe aceptar un parámetro opcional redondear que, si es True, redondee el resultado a 2 decimales.

def promedio(*numeros, redondear=False):
    if not numeros:
        return 0
    
    resultado = sum(numeros) / len(numeros)
    return round(resultado, 2) if redondear else resultado

# Ejemplos de uso
print(promedio(10, 20, 30))  # 20.0
print(promedio(5, 10, 15, 20, redondear=True))  # 12.5
print(promedio(1, 2, 3, 4, 5, redondear=True))  # 3.0

5. Funciones Lambda (Anónimas)

Son funciones pequeñas y anónimas que pueden tener cualquier número de argumentos, pero solo una expresión.

# Función lambda para calcular el cuadrado de un número
cuadrado = lambda x: x ** 2
print(cuadrado(5))  # 25

# Uso común con funciones como sorted()
puntos = [(1, 2), (3, 1), (5, 0), (2, 4)]
puntos_ordenados = sorted(puntos, key=lambda punto: punto[1])
print(puntos_ordenados)  # [(5, 0), (3, 1), (1, 2), (2, 4)]

Consejo: Las funciones lambda son útiles para operaciones simples que se pueden escribir en una sola línea. Para lógica más compleja, es mejor usar funciones regulares con def.

Proyecto Práctico

Sistema de Gestión de Tareas

Crea un programa que permita gestionar una lista de tareas pendientes. El programa debe permitir al usuario agregar, ver, marcar como completada y eliminar tareas.

Requisitos:

  1. Usar funciones para cada operación (agregar, ver, completar, eliminar).
  2. Almacenar las tareas en una lista de diccionarios, donde cada diccionario represente una tarea con las siguientes propiedades:
    • id (número único)
    • descripcion (texto de la tarea)
    • completada (booleano)
    • fecha_creacion (fecha y hora de creación)
  3. Mostrar un menú interactivo que permita al usuario seleccionar la operación deseada.
  4. Validar las entradas del usuario.

Menú de ejemplo:

=== Gestor de Tareas ===
1. Ver todas las tareas
2. Agregar tarea
3. Marcar tarea como completada
4. Eliminar tarea
5. Salir
Seleccione una opción: 
from datetime import datetime

# Lista para almacenar las tareas
tareas = []

# Contador para generar IDs únicos
contador_id = 1

def obtener_fecha_actual():
    """Devuelve la fecha y hora actual formateada"""
    return datetime.now().strftime("%d/%m/%Y %H:%M")

def agregar_tarea(descripcion):
    """Agrega una nueva tarea a la lista"""
    global contador_id
    tarea = {
        'id': contador_id,
        'descripcion': descripcion,
        'completada': False,
        'fecha_creacion': obtener_fecha_actual()
    }
    tareas.append(tarea)
    contador_id += 1
    print(f"Tarea agregada con éxito (ID: {tarea['id']})")

def ver_tareas(mostrar_completadas=True):
    """Muestra todas las tareas"""
    if not tareas:
        print("No hay tareas pendientes.")
        return
    
    print("\n=== LISTA DE TAREAS ===")
    for tarea in tareas:
        if not mostrar_completadas and tarea['completada']:
            continue
            
        estado = "✓" if tarea['completada'] else " "
        print(f"[{tarea['id']}] [{estado}] {tarea['descripcion']}")
        print(f"   Creada: {tarea['fecha_creacion']}")

def marcar_completada(id_tarea):
    """Marca una tarea como completada"""
    for tarea in tareas:
        if tarea['id'] == id_tarea:
            if tarea['completada']:
                print(f"La tarea {id_tarea} ya está marcada como completada.")
            else:
                tarea['completada'] = True
                print(f"Tarea {id_tarea} marcada como completada.")
            return
    print(f"No se encontró la tarea con ID {id_tarea}")

def eliminar_tarea(id_tarea):
    """Elimina una tarea de la lista"""
    for i, tarea in enumerate(tareas):
        if tarea['id'] == id_tarea:
            confirmacion = input(f"¿Estás seguro de eliminar la tarea '{tarea['descripcion']}'? (s/n): ")
            if confirmacion.lower() == 's':
                tareas.pop(i)
                print(f"Tarea {id_tarea} eliminada correctamente.")
            return
    print(f"No se encontró la tarea con ID {id_tarea}")

# Menú principal
def mostrar_menu():
    while True:
        print("\n=== GESTOR DE TAREAS ===")
        print("1. Ver todas las tareas")
        print("2. Ver tareas pendientes")
        print("3. Agregar tarea")
        print("4. Marcar tarea como completada")
        print("5. Eliminar tarea")
        print("6. Salir")
        
        opcion = input("\nSeleccione una opción: ")
        
        if opcion == '1':
            ver_tareas()
        elif opcion == '2':
            ver_tareas(mostrar_completadas=False)
        elif opcion == '3':
            descripcion = input("Ingrese la descripción de la tarea: ").strip()
            if descripcion:
                agregar_tarea(descripcion)
            else:
                print("La descripción no puede estar vacía.")
        elif opcion == '4':
            ver_tareas(mostrar_completadas=False)
            try:
                id_tarea = int(input("\nIngrese el ID de la tarea a marcar como completada: "))
                marcar_completada(id_tarea)
            except ValueError:
                print("Por favor, ingrese un ID válido (número).")
        elif opcion == '5':
            ver_tareas()
            try:
                id_tarea = int(input("\nIngrese el ID de la tarea a eliminar: "))
                eliminar_tarea(id_tarea)
            except ValueError:
                print("Por favor, ingrese un ID válido (número).")
        elif opcion == '6':
            print("¡Hasta luego!")
            break
        else:
            print("Opción no válida. Por favor, intente de nuevo.")

# Ejecutar el programa
if __name__ == "__main__":
    mostrar_menu()
