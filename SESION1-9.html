Sesión 1.9: Funciones en Python

Objetivos de Aprendizaje

  • Comprender el concepto de funciones en programación
  • Aprender a definir y llamar funciones en Python
  • Entender los parámetros y argumentos de funciones
  • Explorar el retorno de valores
  • Conocer el alcance de las variables

1. Introducción a las Funciones

Las funciones son bloques de código reutilizables que realizan una tarea específica. Nos permiten organizar el código, hacerlo más legible y evitar la repetición.

Sintaxis básica de una función

def nombre_funcion(parametros):
    """Docstring: Descripción de la función"""
    # Cuerpo de la función
    return valor_retorno

2. Definición y Llamada de Funciones

Vamos a ver un ejemplo práctico de cómo definir y llamar una función simple:

Ejemplo: Función de saludo

def saludar(nombre):
    """Esta función recibe un nombre y devuelve un saludo"""
    return f"¡Hola, {nombre}! Bienvenido al curso de IA."

# Llamando a la función
mensaje = saludar("Ana")
print(mensaje)  # Imprime: ¡Hola, Ana! Bienvenido al curso de IA.

3. Parámetros y Argumentos

Las funciones pueden recibir múltiples parámetros y podemos definir valores por defecto:

Ejemplo: Función con múltiples parámetros

def calcular_imc(peso, estatura):
    """Calcula el Índice de Masa Corporal (IMC)"""
    return peso / (estatura ** 2)

# Llamada con argumentos posicionales
imc = calcular_imc(70, 1.75)

# Llamada con argumentos nombrados
imc = calcular_imc(estatura=1.75, peso=70)

4. Valores de retorno

Las funciones pueden devolver múltiples valores usando tuplas:

Ejemplo: Retorno múltiple

def operaciones(a, b):
    """Realiza operaciones básicas y devuelve múltiples valores"""
    suma = a + b
    resta = a - b
    multiplicacion = a * b
    division = a / b if b != 0 else "Error: división por cero"
    return suma, resta, multiplicacion, division

# Desempaquetado de la tupla retornada
s, r, m, d = operaciones(10, 5)
print(f"Suma: {s}, Resta: {r}, Multiplicación: {m}, División: {d}")

5. Alcance de Variables

Las variables pueden ser globales o locales según donde se definan:

Ejemplo: Variables locales y globales

# Variable global
contador = 0

def incrementar():
    # Para modificar una variable global dentro de una función
    global contador
    contador += 1
    # Variable local
    mensaje = f"Contador: {contador}"
    return mensaje

print(incrementar())  # Contador: 1
print(incrementar())  # Contador: 2

Ejercicios Prácticos

Ejercicio 1: Calculadora de Factorial

Crea una función que calcule el factorial de un número entero no negativo.

def factorial(n):
    """Calcula el factorial de un número"""
    if n == 0 or n == 1:
        return 1
    return n * factorial(n - 1)

# Ejemplo de uso
print(factorial(5))  # 120

Ejercicio 2: Contador de Vocales

Escribe una función que cuente cuántas vocales tiene una cadena de texto.

def contar_vocales(texto):
    """Cuenta el número de vocales en un texto"""
    vocales = 'aeiouAEIOUáéíóúÁÉÍÓÚ'
    contador = 0
    for letra in texto:
        if letra in vocales:
            contador += 1
    return contador

# Ejemplo de uso
print(contar_vocales("Hola Mundo"))  # 4

Resumen de la Sesión

  • Las funciones nos permiten organizar el código en bloques reutilizables.
  • Podemos definir funciones con def y llamarlas por su nombre.
  • Las funciones pueden recibir parámetros y devolver valores.
  • Es importante entender el alcance de las variables (globales y locales).
  • Las funciones pueden devolver múltiples valores usando tuplas.
